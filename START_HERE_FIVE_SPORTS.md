# SportsLab: five-sport tactical research workbench

The original four-sport match-outcome benchmark remains preserved in `README.md`.
This extension asks more detailed questions about actual recorded actions and
physical execution. It is an independent, AI-assisted, noncommercial research
project for learning and portfolio discussion, with source-specific use conditions.

## What the seven studies mean

| Sport | Event/tactical study | Separate physical-execution companion |
|---|---|---|
| Soccer | WSL shot geometry and selectively recorded defensive positions | Pose measurement research only; no unvalidated contact-angle outcome model |
| Basketball | ACB shot release, distance, clock and defensive contest context | Laboratory/pose source-quality research only |
| Baseball | MLB swing/contact tendencies from count and observed pitch-outcome sequences | Adult machine-pitch laboratory body angles and recorded exit velocity |
| American football | NFL retrospectively charted at-snap formation, personnel and motion | Literature and measurement-gap map for blocking, leverage and mechanics |
| Tennis | Professional charted first/second-serve direction tendencies | Collegiate stated-target, net-censoring and measured bounce execution |

These are different targets and populations. There is no meaningful single
“five-sport accuracy” score. A probability, conditional count, estimated joint
angle, measured bounce and hypothetical intervention require different evidence.
The research inventory explains the important factors that remain unmeasured.

## Open the local workbench

Install the base dependencies as described in the original README, then run:

```sh
python -m experiments.tactical.workbench index
python -m experiments.tactical.workbench serve --port 8765
```

Open `http://127.0.0.1:8765`. This is a read-only loopback application with local
assets. It does not fetch data, fit models, send telemetry or publish a service.
Absent source summaries or independently reviewed model views are shown as
unavailable rather than replaced with invented examples.

A sanitized distribution can show a separately audited aggregate snapshot. It
contains no tactical weights or row-level data, so that snapshot is not a live
trained predictor or a fresh reproduction. Source/parser commands and pinned
protocols support a full local research installation under the applicable terms.

## Read the evidence in order

1. `docs/research/FIVE_SPORT_RESEARCH_SYNTHESIS.md`: literature, factor coverage and measurement limits
2. `docs/tactical/WORKBENCH.md`: what the displays mean and how they are checked
3. `docs/tactical/model_cards/`: each study’s target, denominator, timing and limitations
4. `docs/tactical/*PROTOCOL_DRAFT.md` and `TENNIS_EXECUTION_PROTOCOL_PUBLIC.md`: reviewed experiment specifications; the public tennis-execution copy removes individual source values without changing its numerical method. “DRAFT” is a preserved filename, not permission to change a bound run
5. `docs/tactical/LEARNING_GUIDE.md`: exercises to understand, reproduce and extend the work honestly
6. `docs/tactical/notices/` and `docs/research/notices/`: attribution and source-specific restrictions

The per-runner technical guides preserve their implementation-handoff wording;
the benchmark and result cards state the current measured status. A fresh full
research run requires the pinned licensed sources, reviewed local bindings and
the explicit development/evaluation stages. The aggregate ZIP is usable without
those private artifacts, but it cannot by itself reproduce fitted predictions.

## Engineering and scientific boundaries

- Data and parser hashes, fixed cohorts, feature timing, fit budgets, training-only
  transforms, saved predictions and independent metric checks make the research auditable
- The original four-sport benchmark has a separate clean reproduction check.
  The tactical extension has not yet been rerun end-to-end from a fresh source root;
  its current checks must not be described as a fully independent refit replication
- Final periods are performance-blind after source QA; source inspection sometimes
  exposed later annotations or marginal outcomes. This is not a prospective clinical-style blind trial
- Chronological tests and grouped laboratory folds answer different generalization questions
- All prespecified comparisons, including ties, unavailable procedures and regressions,
  belong in the report. Final scores cannot justify another round of hidden tuning
- No model estimates injury, health, readiness, causal coaching effects or individual
  selection/ranking. No betting or paid/private data integration is included
- Automated functional and DOM tests have been run. The environment blocked a real
  Chromium visual check; rendered layout and accessibility still require local inspection
