# Reproducible numerical stages

The seven tactical studies extend the original four match-outcome forecasters.
Those forecasters, their historical comparisons and their release remain frozen.
There is no single cross-sport accuracy: these studies answer different questions
on different units and populations.

## What is fixed before fitting

Each task has a source and measurement contract, exact eligible denominator,
feature availability rule, finite candidate budget and prespecified comparison.
The files named `*_PROTOCOL_DRAFT.md` retain the reviewed statistical specification;
their names alone neither authorize execution nor describe its current status.
A run binding records the actual code, protocol, input bytes, runtime and threads.
An independent numerical review must identify that exact binding and clear its
stage. A source-only review cannot serve as numerical clearance.

The shared gate is a local reproducibility safeguard, not an authentication or
security system. It does not make retrospective annotations a live data feed.

## Development

- Soccer: WSL season-based expanding validation, then the fixed calibration block
- Basketball: four expanding folds among the first five ACB games, without tuning
  or a recalibrator
- Baseball: 2023 fitting, first-half-2024 selection, second-half-2024 calibration;
  the game spanning that boundary is excluded from those parameter partitions
- American football: 2023 fitting, weeks 1–9 of 2024 selection, weeks 10–18 calibration
- MCP tennis: four first/second-serve and source-corpus cells, with the explicit
  assumed 21-day availability rule at history and parameter boundaries
- Baseball mechanics: the fixed five-outer/four-inner athlete-grouped procedure
- Tennis execution: eight leave-player-out fixed hurdle-model comparisons

All numerical attempts are reserved before estimation. Failures count toward the
budget and cannot quietly trigger a new solver, feature set, split or target.
Only explicitly specified retries may occur. Training transformations are fit on
the corresponding training rows; selection and calibration retain distinct roles.

For the two grouped mechanics studies, development writes every out-of-group
prediction before outer-fold performance is inspected. This is a fixed nested or
leave-player-out estimate, not an untouched chronological lockbox. Their target
measurements were previously inspected for source QA and marginal descriptions.

## Cross-task final-evaluation barrier

The exact evaluation cohort is the five event tasks plus the two mechanics
companions. Each binding records that cohort. The global freeze must contain
exactly all seven named selection commitments, and all commitments, inputs and
code must still match. A one-task subset cannot unlock final performance.

Soccer, baseball and football save immutable final probabilities before joining
final labels. MCP tennis uses the fixed full-2025 availability cutoff of 22 January
2026, rather than a caller-selected partial year. It follows the specified
past-only history rule within that year. Basketball saves and hashes each next
game's predictions before that game's labels can update the following game's
training history, and computes scores only after all five later games are saved.
That stage includes exactly ten predeclared sequential logistic fits; the other
tasks score frozen fitted procedures. Basketball is sequential prequential
evaluation, not one static final model or a scoring-only operation.

Source QA has already examined some later-period annotations. The honest label
is **performance-blind after source QA**, not human-blind or prospective evidence.
A negative final comparison remains a negative result; final outcomes never pick
a replacement model.

## Verification and delivery

Independent checks cover source-to-cache fidelity, explicit label access, group
and time isolation, preprocessing, budget accounting, serialization and saved
prediction/metric parity. Classification reports name class order, log clipping,
Brier convention, reliability bins and support. Cluster uncertainty is reported
only under the task's declared assumptions; repeated observations do not become
independent athletes or games.

Measured mechanics retain physical units and sensor-specific definitions.
OpenBiomechanics uses the fixed adult paired cohort. BYU retains net-censored
non-let attempts and never invents their unobserved bounce locations. Public or
shared reports remain aggregate-only, subject to source-specific terms and a
separate privacy review. Local raw rows, coded participant memberships and model
artifacts are not automatically included in a source-code release.

The local workbench currently exposes validated descriptive views. Predictive
views require completed, independently checked numerical reports. DOM and static
checks have passed; browser-rendered visual QA is still blocked by the current
execution environment and is not claimed as completed.
