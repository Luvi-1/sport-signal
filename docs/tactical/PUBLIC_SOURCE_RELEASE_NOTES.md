# Public source copies and reproducibility boundaries

The numerical results belong to the preserved, independently audited executed
sources and private run commitments. This source-only distribution deliberately
uses four privacy/distribution-only copies. It is not a fresh tactical refit,
an executable trained predictor, or a claim that published code hashes equal the
executed-source hashes. Original benchmark files and frozen originals are unchanged.

## Four fixed changes

- The mechanics parser changes one explanatory limitation string to omit an
  observed source speed extremum; parser logic, measurements and scoring are unchanged
- Its synthetic test replaces that observed value with the deliberately fabricated,
  nonphysical value 1000.25, with an explicit synthetic-fixture comment
- The tennis-execution protocol has a distinct PUBLIC filename, omits observed
  speed extrema and makes all participant-level diagnostics local-only; targets,
  cohorts, models, fitting budgets, uncertainty and comparison specifications are unchanged
- The public mechanics runner changes one protocol-path literal to the included
  PUBLIC filename; no estimator, predictor, feature, group, selection or budget changes

Code and test archive paths remain import-compatible. The public protocol is
docs/tactical/TENNIS_EXECUTION_PROTOCOL_PUBLIC.md; the executed DRAFT protocol
is not included. Original/public identities and exact span-change provenance
are bound in TACTICAL_PUBLISH_MANIFEST.json. The original identities below remain
the identities used in private execution and evaluation.

## Local-only audit references

Some historical research and source-quality documents are intentionally omitted
after privacy review. References to those documents in retained historical source
or method notes describe local audit provenance, not missing public data that
should be reconstructed or fetched from an unaffiliated mirror. In particular,
private memberships, source-case predictions, participant diagnostics, source
acquisition records and original run commitments are absent.

Omitted historical notes include the independent method-review narrative, bounded
SPL schema addendum, OpenBiomechanics audit, baseball/football research brief,
football other-role review and the two tennis source-contract/model-design notes.
The current public workbench method route uses EXECUTION_STAGES.md.

The sanitized bundle supports review of source, methods and independently cleared
aggregate views. A clean local refit requires separately rights-cleared source
inputs, regeneration and independent review of new source/protocol bindings and
all ordinary numerical gates. The one public protocol-path repair is a resolution
check, not a claim that omitted inputs, reviews and private evidence are bundled.
