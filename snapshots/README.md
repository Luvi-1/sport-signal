# Frozen, licensed NFL research input

This is a compact **normalized** 2010–2025 non-tied regular-season results
snapshot, not the original provider download. It contains no odds or private user
data. It is included so a changing nflverse release cannot silently break exact
historical reproduction.

Data: Lee Sharpe and nflverse, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
See LICENSE.nflverse.md and nfl_regular_2010_2025.json for the actual provider URL,
retrieval date, original source hash, normalized representation hashes and changes.
The code's MIT license does not relicense these records. No endorsement is implied.

The V1 reproduction uses only seasons2010–2024; V2 uses2010–2025 under its
separate temporal protocol. Checksums verify both normalized subsets against
originally audited outputs. An explicit refresh exports newly fetched candidate
results elsewhere for review; it does not overwrite frozen reports or inputs.

All other downloaded datasets, per-event features/predictions and trained weights
remain excluded from Git. Tennis source rights remain non-commercial/share-alike.
